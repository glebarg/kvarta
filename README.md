# Кварта — лендинг для обжарки кофе

Веб-сайт для небольшой кофейной мастерской из Минска. Основная задача — рассказать о проекте, показать ассортимент и помочь посетителям оставить заявку на покупку кофе или оформление подписки.

## Что было сделано

1. **Разработка интерфейса.** Создал адаптивную вёрстку сайта с информацией о мастерской, ассортиментом кофе, ценами, подпиской, условиями доставки и контактами.
2. **Тестирование и исправление ошибок.** Проверил работу сайта, изучил логи, выявил проблемы и доработал вёрстку и стили для улучшения отображения на разных устройствах.
3. **Форма заявок.** Реализовал отправку заявок через backend. Добавил проверку белорусских номеров телефонов и защиту от повторной отправки заявки в течение 10 минут.
4. **Telegram-уведомления.** Добавил бота, который отправляет менеджеру уведомления о новых заявках.
5. **Отслеживание источников трафика.** Реализовал сбор данных о рекламных источниках и переходах, чтобы понимать, откуда приходят потенциальные клиенты.
6. **Контейнеризация и развёртывание.** Настроил Docker Compose для упрощения запуска приложения и его развёртывания на стороннем сервере.

## Технологии

- **Frontend:** React, TypeScript, Vite
- **Backend:** Python, FastAPI
- **База данных:** SQLite, SQLAlchemy
- **Интеграции:** Telegram Bot API
- **Инструменты:** Docker, Docker Compose, Git

## Хранение заявок

Для хранения заявок используется SQLite с SQLAlchemy. Это простое решение для небольшого проекта: не требуется разворачивать отдельный сервер базы данных, а заявки сохраняются между перезапусками приложения.

## Запуск проекта

Запуск основных сервисов:

```bash
docker compose up --build -d
```

Запуск Telegram-бота:

```bash
docker compose --profile telegram up -d --build telegram-bot
```

Для полноценной работы необходимо настроить переменные окружения в `.env` на основе `.env.example`.

## Работа с ИИ

ИИ использовался как вспомогательный инструмент при разработке и исправлении ошибок. Результаты проверялись вручную: тестировалась работа сайта, анализировались логи и проверялись исправления.
